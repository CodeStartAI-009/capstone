# Chrome extension (Manifest V3)

The extension checks the **current tab's URL** with the project's Flask API when
you click its toolbar icon.
- It contains **no model and no prediction logic**. It shows exactly what
  `POST /api/predict` returns, the same result the web app shows for the same
  URL.
- It never blocks, modifies or reads a page.

```
toolbar click -> popup.js reads the active tab URL (activeTab)
              -> POST {API_BASE}/api/predict {"url", "source": "extension", "record": true}
              -> Flask -> ml.predictor -> final model -> JSON
              -> popup shows the verdict, prediction, risk level, model confidence, reasons and disclaimer
```

## Files

| File | Purpose |
|---|---|
| `extension/manifest.json` | MV3 manifest |
| `extension/config.js` | **The only place the API location is set** (`API_BASE`, request timeout) |
| `extension/popup.html` / `popup.css` / `popup.js` | Popup UI and logic |
| `extension/icons/` | PNG icons, generated by `python scripts/make_icons.py` |

There is **no background service worker and no content script.** The popup does
the work, so the extension needs no permission to run in the background or
inside pages. An earlier version scanned every page load in the background with
the `tabs` permission. That sent the user's whole browsing stream to the API,
so it was removed.

## Permissions

| Permission | Why |
|---|---|
| `activeTab` | Lets the popup read the URL of the tab you clicked the icon on, only at that moment. No access to other tabs, history or page content. |
| `host_permissions: ["http://127.0.0.1:5000/*"]` | Lets the popup call the API cross-origin. Only the API origin is listed. |

Not requested: `tabs`, `history`, `storage`, `scripting`, `webRequest`,
`cookies`, `<all_urls>`, content scripts or a background worker.
`tests/test_client_code.py` enforces this list. The extension CSP is
`script-src 'self'; object-src 'none'; base-uri 'none'`.

## Installation (developer mode)

1. Start the API: `python app.py`. It must listen on `http://127.0.0.1:5000`,
   or change the configuration below.
2. Open `chrome://extensions` and switch on **Developer mode** (top right).
3. Click **Load unpacked** and select the project's `extension/` folder.
4. Pin *Phishing URL Scanner* from the puzzle-piece menu, open any web page and
   click the icon.

## API base URL configuration

| Environment | `extension/config.js` | `extension/manifest.json` |
|---|---|---|
| Development (default) | `const API_BASE = "http://127.0.0.1:5000";` | `"host_permissions": ["http://127.0.0.1:5000/*"]` |
| Production | `const API_BASE = "https://YOUR-PRODUCTION-API";` | `"host_permissions": ["https://YOUR-PRODUCTION-API/*"]` |

No production API exists yet, so none is configured. Both lines must name the
same origin, and `tests/test_client_code.py` checks that they agree. After
editing, click **Reload** on `chrome://extensions`.
- **macOS:** if port 5000 is taken by the AirPlay receiver, start Flask with
  `API_PORT=5051` and use `http://127.0.0.1:5051` in both places.
- **Production:** also set the API's `CLIENT_ORIGIN` if a web frontend is
  hosted elsewhere. The extension itself doesn't need CORS, because
  `host_permissions` covers it.

## Popup behaviour

| Situation | Popup shows | Sent to API? |
|---|---|---|
| http(s) page | Verdict (e.g. "Low-risk prediction"), prediction, risk level, model confidence, up to 4 reasons, disclaimer with the measured recall; **View details** (opens `/inspect?id=N`) and **Open dashboard** | yes (`record: true`, `source: extension`) |
| `chrome://`, `about:`, `data:` pages | "This page cannot be scanned. Only http:// and https:// web pages can be checked…" (Chrome does not reveal these URLs to `activeTab`) | no |
| `file://` page | "…This tab shows local files." | no |
| Malformed host / internal host (`localhost`, private IP) | The API's validation message | yes (rejected by the API with 400, not stored) |
| API not running | "Cannot reach the scanner API at … Start the Flask server (python app.py) and try again." | n/a |
| No answer within 8 s | "The scanner API did not respond within 8 seconds. Try again." | n/a |
| API error / non-JSON response | The API's friendly message, or "unexpected response (HTTP n)" | n/a |

**Scan again** re-runs the scan, and repeat clicks are ignored while a request
is in flight. All text is set with `textContent`; the popup never uses
`innerHTML` and never executes page content.

## Privacy

- Only the current tab's URL is sent, only when you click the icon, and only to
  `API_BASE`.
- The extension stores nothing: no `storage` permission, no cache.
- The API saves the scan to its local history with query values redacted (see
  `docs/database.md`).

## Testing

`tests/browser/test_extension_browser.py` has 14 tests. It uses headless Chrome
driven over the DevTools protocol:
- `Extensions.loadUnpacked` loads a copy of `extension/` in which only the API
  origin differs (pointing at a test server).
- `Extensions.triggerAction` simulates the toolbar click, so Chrome grants the
  real `activeTab` permission.
- Web pages are served by request interception, so no internet access is
  needed.

What it covers:

| Area | Tests |
|---|---|
| Real API | Normal HTTPS page (result identical to the web app's API result for the same URL; stored as `source=extension`), suspicious HTTP page, View details / Open dashboard buttons |
| Pages not sent to the API | `chrome://version`, `about:blank`, `data:`, `file://` |
| API validation errors | Malformed host, localhost |
| API failures | Unavailable, 8 s timeout, 500 error, non-JSON 502 |
| Popup rendering | Markup in the URL shown as inert text, no rendered hidden elements, no overflow, no console errors |

Static checks in `tests/test_client_code.py` cover:
- the MV3 manifest and minimal permissions;
- that referenced files exist;
- that the API origin is configured in one place;
- no `innerHTML`/`eval`, no inline scripts, no secrets.

Manual installation through the `chrome://extensions` **Load unpacked** dialog
could not be automated here, because the folder picker is a native dialog.
`Extensions.loadUnpacked` loads the same unpacked folder programmatically.
